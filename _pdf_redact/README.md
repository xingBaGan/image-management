# PDF 涂黑 / 替换 工具

用途：把你自己 PDF 上的敏感信息（地址、电话、卡号、身份证号…）**永久性涂黑**，
或涂掉后**替换成其他文字**。底层文字流一并删除，被涂到的图片像素也会真正抹除，
别人无法通过复制粘贴或选中还原原文。

> ⚠️ 请仅用于你有权处理的文件。**不要**用它篡改银行对账单、发票、合同等他人出具的正式文件后再对外使用——那属于伪造文书。

## 依赖

只需要 [uv](https://docs.astral.sh/uv/)（Python 依赖会由脚本顶部的 PEP 723 元数据自动准备）：

```bash
brew install uv
# 或者:
curl -LsSf https://astral.sh/uv/install.sh | sh
```

## 三种定位方式

| 参数 | 用途 | 什么时候用 |
|---|---|---|
| `-t/--text "xxx"` | 按字面量文本搜索 | PDF 里目标是**真正的可搜索文字** |
| `-r/--regex "..."` | 按正则搜索 | 卡号、手机号等有格式规律的批量字段 |
| `--rect "P:x0,y0,x1,y1"` | 按坐标矩形 | 目标是**图片**、或文字层被打散/字符不匹配 |

前两种找不到 → 说明目标不是文字层（常见于某些银行对账单，中文以逐字小图片渲染）→ 改用 `--rect`。

## 替换文字

涂黑后写入新文本（有替换时默认白底黑字）：

| 参数 | 用途 |
|---|---|
| `--replace "新文字"` | 全局替换，对 `-t` / `-r` / `--rect` 都生效 |
| `--rect "P:x0,y0,x1,y1=新文字"` | 单个矩形各自指定替换（优先于 `--replace`） |
| `--fontsize 10` | 字号（默认 11） |
| `--fontfile PATH` | 自定义 TTF/OTF；**默认自动用系统 Songti SC Light 细宋体** |
| `--font china-s` | 仅在无细体字体文件时使用的内置字体 |

## 使用

```bash
cd _pdf_redact

# 1) 先预览: 看看哪些位置会被涂黑, 不写文件
uv run redact_pdf.py 输入.pdf -o 输出.pdf -t "138-1234-5678" --preview

# 2) 按文本涂
uv run redact_pdf.py 输入.pdf -o 输出.pdf -t "北京市朝阳区xx路123号"

# 一次涂多条
uv run redact_pdf.py 输入.pdf -o 输出.pdf \
    -t "北京市朝阳区xx路123号" \
    -t "138-1234-5678"

# 3) 按正则批量涂 (例: 所有 16 位卡号)
uv run redact_pdf.py 输入.pdf -o 输出.pdf -r "\d{4}[- ]?\d{4}[- ]?\d{4}[- ]?\d{4}"

# 4) 按矩形涂 (页码从 1 开始, 坐标单位是 PDF pt, 页面左上角 = (0,0))
uv run redact_pdf.py 输入.pdf -o 输出.pdf --rect "1:58,130,260,172"

# 一次涂多个矩形
uv run redact_pdf.py 输入.pdf -o 输出.pdf \
    --rect "1:58,130,260,172" \
    --rect "1:490,125,538,160"

# 5) 矩形涂掉后换成新文字
uv run redact_pdf.py 输入.pdf -o 输出.pdf \
    --rect "1:58,130,260,172" --replace "新地址内容" --fontsize 10

# 6) 多个矩形各自替换不同文字
uv run redact_pdf.py 输入.pdf -o 输出.pdf \
    --rect "1:58,130,260,172=北京市朝阳区某某路1号" \
    --rect "1:490,125,538,160=13800000000"

# 7) 搜到旧文字后替换成新文字
uv run redact_pdf.py 输入.pdf -o 输出.pdf \
    -t "旧地址" --replace "新地址" --fontsize 10

# 8) 用白色矩形代替黑色 (适合浅色背景; 有 --replace 时已默认 white)
uv run redact_pdf.py 输入.pdf -o 输出.pdf --rect "1:58,130,260,172" --fill white
```

### 找矩形坐标: `--render-grid`

如果不知道要涂哪个矩形，用这个模式生成每页的**带坐标网格 PNG**：

```bash
uv run redact_pdf.py 输入.pdf --render-grid ./grid
```

然后 `./grid/page1_grid.png` 打开，图上每 10pt 一条浅线、每 50pt 一条深线并标注 `x=`/`y=` 数字。目测你要涂的矩形范围（比如地址所在 x=58-260, y=130-172），再传给 `--rect`。

## 注意事项

- **PDF 坐标单位是 pt**（1pt = 1/72 英寸），页面左上角是 `(0, 0)`。A4 页面 ≈ `(595, 842) pt`。
- **替换文字**：矩形要够宽，字号过大或文字过长会挤在框内；中文请保持默认 `--font china-s`。
- **确认输出**：跑完请用 PDF 阅读器打开，尝试选中/复制被涂黑的区域，确认拿不到原文，再对外发送。
- 原文件不会被修改，永远写到新的 `-o` 输出路径。
- 加密的 PDF 如果不需要密码就能读（open 后仍可访问），本脚本能处理；否则需要先解密。
